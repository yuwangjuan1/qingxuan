# 青选 QingXuan

高考志愿决策平台：不预测分数线，只教你怎么选。

## 定位

大厂的免费 AI 工具解决「能上哪些学校」，青选解决「该上哪个、怎么一家人达成一致」。
纯方法论口径：不提供分数线/录取概率数据，不承诺录取结果，规避数据壁垒与幻觉责任。

## 模块

- 学校介绍（/schools）：院校结构化卡片，实力/转专业政策/避坑点
- 专业定位（/majors）：拆名字、四出口地图、名称陷阱标注
- 择校工具（/tools）：冲稳保梯度自查、防退档终检、专业二选一矩阵（纯本地计算）
- 竞争与就业（/insights）：专业方向红绿灯，定性分析附来源口径
- AI 顾问（/chat）：青杏（策略）/ 青棠（专业）/ 青梧（家庭调解），SSE 流式对话

## 技术

Next.js 16 + React 19 + Tailwind v4，无数据库（数据在 lib/data/ TS 文件），
大模型走 OpenAI 兼容协议（默认千问，可换 GLM/DeepSeek）。

## 运行

```bash
cp .env.example .env.local   # 填入 LLM_API_KEY
npm install
npm run dev
```
